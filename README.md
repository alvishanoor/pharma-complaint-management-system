# Pharma Customer Complaint Management System

AI-powered customer complaint intake and risk triage system for pharmaceutical
manufacturing (API/FDF), built for the AIVOA.AI Round 1 assignment.

## Tech Stack
- Frontend: React (Vite) + Redux Toolkit + Axios
- Backend: Python FastAPI
- AI Agent Framework: LangGraph (2-node conditional graph)
- LLM: Groq (openai/gpt-oss-20b for text, qwen/qwen3.6-27b for vision)
- Database: SQLite via SQLAlchemy

## Features
- Manual complaint intake form
- AI Copilot chat-based intake (paste complaint text, auto-fills form)
- Document/image upload (PDF, text, photos) with AI field extraction
- LangGraph-powered risk triage: completeness check -> risk classification
